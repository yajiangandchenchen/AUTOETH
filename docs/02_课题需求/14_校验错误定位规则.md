# Shared customer contract: exact direct CodecResult coordinates

This is the complete coordinate table approved under Q019, including its context, checked arithmetic and error-order rules. The successful result `0 / 0 / 0` is a no-error-location sentinel. The absolute-location and identifiable-node guarantees below apply to results carrying an error location; they do not reinterpret success as a payload at absolute byte zero.

固定现有14个CodecCode、byteOffset:uint64、nodeId:uint32、dataId:uint16，不加字段。仅直接CodecResult保证完整字段；Runtime Status保留其窄detail/byteOffset和有损诊断环边界。

坐标基准：有LayoutContext的payload调用令O=absolute_payload_origin_bytes；没有该参数的直接normalize/compile入口令O=0，所述偏移以其自己的输入view开头为0。所有位置都用checked加法；不能表示绝对坐标时报告LengthOverflow，byteOffset=O，不回绕。nodeId为实际受影响schema节点；调用级问题为合法已知root；确实无法识别节点才0。dataId为当前已完整确定的12-bit成员tag，包含合法0；非tag上下文或无法确定时0。未知tag使用其实际dataId，nodeId为已知包含对象，不捏造未知child node。

错误优先级继续现有范围/完整prefix/父界/重复/文本/默认等合同；单一定位规则不把unknown skip内容拿来强制解码。缺BOM/截断等同时存在时，已有父界完整检查先；text原始extent/max检查先于奇字节处理。长度超过配置max属于既有值/长度错误域时，解码定位其完整长度prefix起点；固定无prefix则该已知值线extent起点。没有长度可用时不从下一字段借字节。

编译校验为使node可复现，沿用现有阶段：顶层字段/节点自身字段按声明顺序 → 全部ID/引用 → 从root按成员/array元素/union声明序遍历检查环/角色 → 完整默认值。非法指针仍是调用者有效内存前提，诊断不能承诺验证任意非NULL地址。原配置loader的ConfigDiagnostic坐标不是CodecResult，不由此改为wire坐标。Classic C转换只按既有类型结果返回；不能因其没有完整CodecResult字段而伪造完整诊断。


## Signature coverage

The eight public functions returning CodecResult are unchanged:

| Function | Coordinate scope |
|---|---|
| `compile_codec_schema(const SchemaSpec&, CompiledSchemaHandle&) noexcept` | No LayoutContext; O=0; configuration-error row. Failed output handle remains unchanged. |
| `measure_payload(const CompiledSchema&, const Value&, const LayoutContext&, size_t&) noexcept` | Supplied absolute origin; schema/value and checked-length preflight rows. Failed byte count remains unchanged. |
| `encode_payload(const CompiledSchema&, const Value&, const LayoutContext&, MutableByteView, size_t&) noexcept` | Supplied absolute origin; preflight/capacity/resource rows before output commitment. |
| `decode_payload(const CompiledSchema&, ByteView, const LayoutContext&, Value&, size_t&) noexcept` | Supplied absolute origin; exact prefix, parent, tag, union, text and missing-member rows. Failed Value and consumed count remain unchanged. |
| `normalize_classic_utf8(ByteView, size_t, Text&) noexcept` | O=0 for the input view, no schema node or DataID. Keep its existing optional-input-BOM normalization domain. |
| `normalize_classic_utf16(const uint16_t*, size_t, size_t, Text&) noexcept` | O=0; source UTF16 unit index converts to byte index by checked multiplication by two. No schema node or DataID. |
| `export_classic_utf8(const Text&, MutableByteView, size_t&) noexcept` | No LayoutContext or schema. O=0; encoding/value/capacity/resource preflight uses zero coordinates. Preserve destination and validUnits on failure. |
| `export_classic_utf16(const Text&, uint16_t*, size_t, size_t&) noexcept` | Same no-context encoding preflight scope; input is Native UTF8 Text, output capacity is in uint16 units. Preserve destination and validUnits on failure. |

All these signatures return the existing CodecResult. The table does not add CodecResult fields to Status-returning header, SD, runtime or configuration functions. Classic C return types and ConfigDiagnostic retain their existing contracts. A diagnostic table is supplied API behavior, not target execution or method approval.


## v1.4 exact root/NULL refinements

For the explicitly bounded whole-root prefix-free fixed Array with known fixed positive element width, complete missing required elements without a legal default use MissingRequired10 at that element node and parentEnd, dataId0. Whole complete extras are skipped under the precise root-only contract; partial elements are not default-spliced.

For a complete NULL Union selector with nonzero exact Union data extent, use ValueRange4 at the first forbidden data byte immediately after the selector, the Union node and actual current DataID. This is not UnknownUnionSelector and does not replace general configured-max/prefix bounds. Apply the current extent/selector priority in 18_根数组_Union与NULL边界.md; no private fixture identity or coordinate value is supplied here.
