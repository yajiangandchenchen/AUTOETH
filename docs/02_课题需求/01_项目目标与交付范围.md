The Native API, configuration grammar and demonstration application protocol are supplied customer design and API prepared during this round. This package contains no implementation or executed result. Stage authorization comes from the coordinator's separate instruction.

Deliver a useful Linux C++14 source SDK with real UDP/TCP communication, IPv4/IPv6, service discovery, RPC and fire-and-forget, events, fields and subscriptions, serialization, TP and E2E. Deliver a working daemon, client and operations tool. The libraries are `autoeth_core`, `autoeth_e2e` and `autoeth_runtime`; their imported CMake targets are `autoeth::core`, `autoeth::e2e` and `autoeth::runtime`. Programs are `autoethd`, `autoeth-client` and `autoethctl`. Dependencies are the C++14/C99 standard libraries, POSIX and Threads. Build all selected production targets, shared/static configurations, installation and relocation, plus independent C99/C++14 consumers.

The authoritative originals are the complete unchanged AUTOSAR R24-11 PDFs and retained RFC originals under `originals/`, with all notices preserved. Distinguish FO wire/protocol requirements from selected CP C APIs and explicit host mappings. Supplied C declaration, member and enum tables are transcription aids. Originals and the three explicit signature adaptations control; the tables are not compiled headers, executed ABI evidence or certification.
