# Shared TP segment payload upper bound

The Native configured `max_segment_payload_bytes` is an upper bound and may be non-multiple-of-sixteen. It does not permit a nonfinal M=1 payload to violate the source sixteen-byte rule.

For a selected TP datagram route, first check that its effective configured/family-limited capacity D can contain the complete twenty-byte SOME/IP plus TP header. Then compute with checked arithmetic:

`rawCapacity = min(configuredMaxSegmentPayload, D - 20)`

`nonfinalPayloadBytes = floor(rawCapacity / 16) * 16`

The nonfinal result must be at least sixteen bytes. Take the minimum before alignment. Do not emit an M=1 segment of seventeen bytes merely because the configured upper bound is seventeen.

A final segment may contain the remaining non-multiple bytes, while still respecting the configured upper bound and actual datagram capacity. Preserve source offset, all-nonfinal-size, message identity, legal length and strategy-specific reassembly rules. Normal default1392 and all aligned inputs keep their prior result.

D remains the configured/family-limited datagram capacity. Do not unconditionally reduce it to observed interface MTU. System IP fragmentation permission, actual EMSGSIZE and other I/O failures remain separate observations. A large localhost datagram is not proof of IP fragmentation.

FO, CP and the finite C host mapping retain their actual header boundaries and parameter units. A full-wire budget subtracts sixteen SOME/IP bytes plus four TP bytes. A Classic local TP PDU begins at Request ID and contains the eight-byte tail plus four TP bytes; translate any inclusive local-PDU budget accordingly. Do not pass the Native payload upper bound as the same numeric value to an original parameter whose unit, header inclusion or range differs. Preserve source-specific narrower constraints and all C signatures/enums.

This replaces the earlier literal min-after-alignment formula. Keep old input and expected versions as history; this is a preimplementation specification refinement, not an observed product defect.
