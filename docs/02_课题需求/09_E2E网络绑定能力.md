# Shared customer contract: pure E2E profiles and Native network bindings

All fourteen selected pure-library profiles remain mandatory: `01`, `02`, `04`, `04m`, `05`, `06`, `07`, `07m`, `08`, `08m`, `11`, `22`, `44` and `44m`. Implement and accept their actual source Init, Protect, Check, Source/Sink, Map and state-machine operations as applicable. Keep the existing source C signatures, selected geometry and legitimate pure-library domains. Existing offline operations remain selected.

The Native normal-profile protected region starts at the eight-byte SOME/IP header tail and then includes the control/application payload. Protect must preserve Client ID, Session ID, protocol version, interface version, message type and return code. E2E control fields must fit safely after these eight bytes. The actual profile configuration and actual buffer extent must satisfy the already specified source and host checks. Method-profile regions retain their separately specified extraction and payload geometry.

| Profile | Pure library | Normal Native communication binding |
|---|---|---|
| `01` | Required, including legacy Init/Protect/Check/Map behavior | Conditional: each active configured write location must avoid the eight-byte SOME/IP tail and fit the actual region. Evaluate its CRC, counter and any selected explicit Data ID nibble geometry; do not reject it solely because it is legacy. |
| `02` | Required, including all original algorithm and legal Offset 0 behavior | Rejected for the selected normal region. Source Offset 0 places its control fields in the Client ID / Session ID bytes. |
| `04` | Required | Available only with a valid configured header location after the protected tail and sufficient actual extent. |
| `04m` | Required | Available only with the selected method region, actual method header extent and configured Source/Sink metadata. |
| `05` | Required | Available only with valid fixed data length and a safe configured header location. |
| `06` | Required | Available only with valid length and a safe configured header location. |
| `07` | Required | Available only with valid length and a safe configured header location. |
| `07m` | Required | Available only with the selected method region, actual method header extent and configured Source/Sink metadata. |
| `08` | Required, including the named Native wide-domain surface | Available only with the appropriate source/wide configuration, valid length and a safe header location; Runtime resource limits remain distinct. |
| `08m` | Required, including the named Native wide-domain surface | Available only with the selected method region, appropriate source/wide configuration, actual method header extent and metadata. |
| `11` | Required | Available only with valid active field locations, selected mode and sufficient actual extent. |
| `22` | Required | Available only with valid fixed length, Data ID list and a safe configured header location. |
| `44` | Required | Available only with valid length and a safe configured header location. |
| `44m` | Required | Available only with the selected method region, actual method header extent and configured Source/Sink metadata. |

Reject a P02 Native normal-network binding during configuration or registration validation, before availability publication and before Protect. Use the existing configuration-error / unsupported-binding diagnostic; no new public enum is introduced. Preserve the existing detailed diagnostic mechanism. Rejection must not commit the requested binding, advertise it as available or mutate an E2E transmit state.

Do not move the caller's data pointer, extend P02 Offset, reorder/copy the header temporarily, modify the source algorithm or silently choose another protected region. A future legacy payload-only network exception would require its own versioned shared contract; it is not selected here.

A correct negative binding case is evidence of rejection, not P02 network success. It does not substitute for actual pure P02 implementation and acceptance. This table describes the selected contractual domains; it is not an execution result and must not be reported as fourteen-profile network support.

The choice applies equally to both development conditions before dependent implementation. Preserve the complete prior question and old input packages. It is an advance consistency decision about the source interface and the supplied protection region, not a code defect or measured method benefit.
