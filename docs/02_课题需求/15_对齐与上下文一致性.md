# Shared customer increment: schema/context default alignment

The compiled `SchemaSpec.defaultAlignmentBits` fixes the wire default. Every call to `measure_payload`, `encode_payload` and `decode_payload` must supply an exactly equal `LayoutContext.default_alignment_bits`.

If the context value is individually legal but differs from the compiled value, return `CodecCode::InvalidSchema` before output/length commitment or another irreversible effect. Validate both fields' legal domains. Measure, encode and decode use the same consistency rule.

Runtime and the configured Classic bridge supply the compiled default and the true full-message absolute origin. Existing SOME/IP header, E2E prefix, node-specific and TLV alignment rules are unchanged. The context is not an undeclared wire-layout override.

Public fields, signatures, source profile types and lengths do not change. Direct `CodecResult` and narrow `Status`/lossy-diagnostic contracts remain as already specified. This shared customer choice is not a product result or method generation authorization. The old versions remain immutable.
