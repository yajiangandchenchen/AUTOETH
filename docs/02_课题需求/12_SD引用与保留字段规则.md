# Shared SD receiver refinements after v1.3.1

Apply this independent overlay after v1.3.1. Preserve the old v1.3/v1.3.1 bytes and all frozen case batches. The complete Q020 receiver order remains, with the following source-specific distinction between actual structure and invalid references.

## Safely located run errors belong to their entry

When the complete message, entry array and every option extent can be located safely, a nonzero run whose index/count exceeds the complete option array is an invalid referenced-option condition for that entry. Detect it before dereferencing an option. Do not turn every logical reference error into a whole-message parse failure.

Apply the existing entry result: Find/Offer ignore, otherwise reply-eligible Subscribe NACK, ACK processing without subscription success, and the other defined per-entry rules. Continue processing other valid entries. Ignore of an SD Endpoint entry reference does not hide a run out of bounds.

Raw parsing preserves the safely located entries and their actual run fields without an out-of-bounds dereference. Required reference validation belongs to the entry/engine phase. A caller must not read uncommitted parse output after a real parse failure. Normal sender runs remain valid.

Count zero creates no reference regardless of its index. With 256 options, index 255/count 1 is legal and index 255/count 2 is not. Check both runs separately with widened/checkable subtraction; do not add narrow uint8 values.

Only an actual message, array or option extent that cannot be safely located retains the whole-message no-earlier-commit structural failure result. This distinction does not relax parent bounds or malformed option extent safety.

## Reserved fields in a valid global SD Endpoint

An otherwise valid first-position, same-family, UDP, unicast, nonzero-port SD Endpoint Option 24/26 keeps its global reply/reboot override when its actual seven-bit header reserved field or later reserved eight-bit field is nonzero. Preserve the raw values and diagnostics. Those reserved values gain no meaning and alone do not invalidate the override.

DF remains a separate real flag. Existing position, count, family, L4, address, port and entry-reference rules remain. Normal local sender reserved fields are still zero. Invalid extent cannot use this tolerance to bypass structure checks. This policy adds no lifecycle, timing, API or public field.

These are common requirements selected before dependent implementation and cases. They are not target execution, software repair or product acceptance.
