## 2. 功能范围（Native 面）

1. **线协议与编解码**：SOME/IP 16B 头（TP 20B）加解帧、UDP 组包/密封、TCP 流分帧、消息校验顺序（protocol→service→interface→method→type→ReturnCode→correlation→payload，见 22 号文档）、按 schema 的序列化（Bool/整数/浮点/TLV/Struct/Array/ByteArray/String/Union/默认值/严格 UTF-8/UTF-16/端序/对齐），8 个直接 `CodecResult` 接口 + 14 个 CodecCode 定位表（14 号文档），根数组/Union/NULL 边界（18 号），有符号二补码线上表示（16 号），成员身份与默认存在性（17 号）。
2. **TP 分段重组**：FO_CONTIGUOUS（Native 默认）与 CP_STREAMING（经典面显式）两套独立状态机；min-before-align 非末段上限（19 号）、超时/取消/丢弃标记、返回码取最后实际接受段等（02 号）。
3. **服务发现与订阅**：FO R24-11 单一 SD 引擎（raw 编解码 + 状态引擎）；Offer/Find/Subscribe/SubscribeAck/SubscribeNack/Stop*；TTL、回退/重启（reboot）选择、负载均衡（Priority/权重/随机抽取，`select_service`）；STATIC / TTL_ONLY / HALF_CYCLE / Magic Cookie 四类控制策略（08 号）；SD 接收端完整顺序、保留位、端口 0、引用越界等（10/11/12 号）。
4. **E2E**：14 个纯库 profile（01/02/04/04m/05/06/07/07m/08/08m/11/22/44/44m）的 Init/Protect/Check/Source/Sink/Map/SM；Native 宽域 P08/P08m 与 SmConfig；E2E 网络绑定能力表（09 号，P02 普通网络绑定在配置/注册阶段拒绝）；运行期收发绑定、源/汇 SM 门槛、保护错误映射 0x80/0x81（02 号）。
5. **运行期**：`Runtime` 全部 21 个方法；RPC 关联/截止时间/取消/恢复、句柄代数分配、事件/字段/订阅、通知 Session Handling（INACTIVE/ACTIVE）、资源账本、诊断环、快照、优雅停机；SecurityProvider 门槛（不含 TLS/加密实现）。
6. **配置加载**：UTF-8 JSON、版本、未知/重复键、引用的校验顺序与 `ConfigDetail` 码（03 号）；`RuntimeConfig` 全字段与默认值（05/06 号）；样例配置全部可加载。

## 3. 功能范围（经典 C 面）

- 标准类型头 `Platform_Types.h` / `Std_Types.h` / `ComStack_Cfg.h` / `ComStack_Types.h`（C99 公开，保原名/顺序/类型）。
- 模块 C API：E2E（含仅 3 处批准的原型适配：04m Sink 指针、07 Map 首参、08m Sink SourceID 指针）、CRC（CRC8/8H2F/16/32P4/64 与版本）、SoAd、PduR、SomeIpTp、Sd、SomeIpXf、E2EXf 的 Finite host 映射。
- `autoeth::classic::bind/unbind` 绑定：模块初始化顺序 PduR→SoAd→SomeIpTp→Sd，共用同一 Runtime 引擎，不另造第二套 SD。

## 4. 演示业务范围（VehicleService）

- 服务 `0x1234`、实例 1、主/次版本 1；方法 ReadSnapshot(1)、ReadBulk(2)、ApplyCalibration(3)、RecordCommand(4, FF)；字段 Calibration getter `0x0100`/setter `0x0101`；事件 VehicleEvent `0x8001`、Calibration 通知 `0x8002`；组 1/2。
- 数据集 1024 字节（00..FF 重复 4 次）以 hex 输入，启动时独占读取并记录哈希；ReadBulk 偏移/长度校验，越界应用错误 1、资源拒绝 3。
- 初始值：快照 revision1 / speed_centi1234 / temperature_deci250 / flags1 / label demo；标定 speed_limit_centi9000 / gain_milli1000 / label baseline；应用错误 1/2/3 映射线上 0x20/0x21/0x22。
- 命令环 128 条，显式不保护 FF，不做持久化/恰好一次。
- 命令行：`autoeth-client` 8 条子命令、`autoethctl` 7 条子命令，退出码 0/2/3/4/5/6/130 约定。

## 5. 质量与证据范围

- 行覆盖 ≥90%、分支覆盖 ≥80%、声明的关键判定极性全覆盖；输出未覆盖/未插桩/缺失需求清单。
- 区分"编译成功/计数/转写"与"产品成功"；证据分离：本地发送完成 ≠ 内核接收 ≠ 对端执行。
- 默认隔离期 60s；happy-path 网络用例使用显式 `fresh_context_asserted` 配置并记录算子假设。
